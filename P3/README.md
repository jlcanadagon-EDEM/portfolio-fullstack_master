# Proyecto 3 - Katas Python

Colección de ejercicios para practicar los fundamentos de Python.

## Contenido

El archivo `katas_python.py` incluye ejercicios sobre:

- Tipos de datos básicos.
- Listas, tuplas, conjuntos y diccionarios.
- Condicionales y bucles.
- Funciones y funciones lambda.
- `map`, `filter` y `reduce`.
- Manejo de excepciones.
- Programación orientada a objetos.
- Uso de módulos.
- Programas interactivos.

## Ejecución

Desde la raíz del repositorio:

```powershell
python .\P3\katas_python.py
```
